# Secret Base

 A gen1recomp++ mod that adds a secret base

The idea here is similar to the secret bases of the Gen 3 games. I plan to make furniture items that will be purchasable from either a vendor or a console in the base and a decoration system.

Every game needs a housing system!

### How to Get to the Base

To get to the base you need the item MYSTIC SHOVEL.

A scientist npc gives this to you in the MT. Moon Pokecenter for free.

If you ever toss the shovel, you can talk to the same npc for another one.

Use the item to teleport to the base.

Use the item again to teleport out of the base.
